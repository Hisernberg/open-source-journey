# Targets — Top Labs' Open Source (the prestige track)

Contributing to foundation-model labs' infrastructure gets your name next to the most-watched repos on GitHub. Pick **1–2 labs** and go deep; these repos are high-traffic, so even small correct PRs get visibility.

| Lab | Repos | Entry angles |
|---|---|---|
| **Anthropic** | `modelcontextprotocol/servers` + MCP SDKs (python-sdk, typescript-sdk), `anthropics/anthropic-sdk-python`, `claude-code` (issues/docs), `anthropics/courses` | MCP server implementations, SDK type fixes, course examples; docs PRs are reviewed fast |
| **Google** | TensorFlow, jax-ml/jax, keras-team/keras + KerasHub, google-ai-edge/mediapipe, Kaggle `kagglehub` + `kaggle-api` | KerasHub model ports; kaggle-api ties into your Kaggle work |
| **Meta** | pytorch/pytorch (torchtune, torchao, torchvision), meta-llama/llama-stack, facebookresearch/sam-2 | test fixes, recipes; PyTorch requires CLA + high bar — start in the satellite repos |
| **Microsoft** | microsoft/onnxruntime, DeepSpeed, semantic-kernel, autogen, guidance-ai/guidance | ONNX op fixes and docs; AutoGen examples |
| **NVIDIA** | NVIDIA/NeMo, TensorRT-LLM, triton-inference-server, RAPIDS | NeMo configs/docs; TRT-LLM kernels are elite track |
| **Apple** | ml-explore/mlx, apple/corenet | MLX ops/examples — newcomer-friendliest lab repo |
| **OpenAI** | openai/whisper, openai/triton, openai/tiktoken, openai/openai-cookbook | cookbook examples, whisper docs, tiktoken edge cases |
| **DeepSeek** | deepseek-ai/open-infra-index (DeepGEMM, FlashMLA) | CUDA elite track — only after profiling confidence |
| **Alibaba** | QwenLM/Qwen-Agent etc., modelscope/FunASR, modelscope/modelscope | Qwen cookbooks, FunASR fixes |
| **Moonshot AI** | moonshotai/Kimi-K2 (K2 repos) | inference integration notes/issues |
| **Z.ai** | zai-org/GLM repos | cookbooks, inference patches |

**Lab-repo etiquette:** read the PR requirements (CLA, issue-first policy, no drive-by refactors). One clean merged PR in a top-lab repo is worth more CV weight than ten trivial ones elsewhere.
